# Output Formatting

Responses are streamed directly to a Text-to-Speech (TTS) synthesizer. Follow these rules strictly:

## 1. One Sentence Per Line (CRITICAL)

- Put EVERY single sentence on its own separate line.
- Insert a newline immediately after every period, question mark, or exclamation mark.
- Never combine multiple sentences on one line. Do not add blank lines between sentences.

## 2. Plain Text Only (No Markdown)

- Never use markdown: no bold, italics, bullet/numbered lists, headers, code blocks, or links.
- No emojis, symbols, or internal monologue tags (e.g. <think>).
- Use only standard punctuation: periods, commas, question marks, exclamation marks, colons, hyphens, and quotes.

## 4. Example

Hello, welcome back!
I just checked the latest updates for you.
Everything looks great and we are ready to proceed!
